# Enforcement types

The types that `check()`, `bulk_check()`, `authorized_users()`, `get_user_permissions()`,
`get_user_tenants()` and `filter_objects()` take and return, on both clients. For how to
model and enforce permissions, see
[Check permissions on docs.permit.io](https://docs.permit.io/how-to/enforce-permissions/check/).
