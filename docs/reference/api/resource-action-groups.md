# Resource action groups

`permit.api.action_groups` is a [`ResourceActionGroupsApi`][permit.api.resource_action_groups.ResourceActionGroupsApi] on the async client and a
[`SyncResourceActionGroupsApi`][permit.api.sync_api_client.SyncResourceActionGroupsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Resource Action Groups](https://api.permit.io/v2/redoc#tag/Resource-Action-Groups).
