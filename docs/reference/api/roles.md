# Roles

`permit.api.roles` is a [`RolesApi`][permit.api.roles.RolesApi] on the async client and a
[`SyncRolesApi`][permit.api.sync_api_client.SyncRolesApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Roles](https://api.permit.io/v2/redoc#tag/Roles).
