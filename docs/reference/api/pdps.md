# PDPs

`permit.api.pdps` is a [`PdpsApi`][permit.api.pdps.PdpsApi] on the async client and a
[`SyncPdpsApi`][permit.api.sync_api_client.SyncPdpsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Policy Decision Points](https://api.permit.io/v2/redoc#tag/Policy-Decision-Points).
