# Projects

`permit.api.projects` is a [`ProjectsApi`][permit.api.projects.ProjectsApi] on the async client and a
[`SyncProjectsApi`][permit.api.sync_api_client.SyncProjectsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Projects](https://api.permit.io/v2/redoc#tag/Projects).
