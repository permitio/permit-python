[`SyncRelationshipTuplesApi`][permit.api.sync_api_client.SyncRelationshipTuplesApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Relationship tuples](https://api.permit.io/v2/redoc#tag/Relationship-tuples).
