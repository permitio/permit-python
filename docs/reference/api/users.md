# Users

`permit.api.users` is a [`UsersApi`][permit.api.users.UsersApi] on the async client and a
[`SyncUsersApi`][permit.api.sync_api_client.SyncUsersApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Users](https://api.permit.io/v2/redoc#tag/Users).
