# Resource relations

[`SyncResourceRelationsApi`][permit.api.sync_api_client.SyncResourceRelationsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Resource Relations](https://api.permit.io/v2/redoc#tag/Resource-Relations).
