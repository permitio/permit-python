# Condition sets

`permit.api.condition_sets` is a [`ConditionSetsApi`][permit.api.condition_sets.ConditionSetsApi] on the async client and a
[`SyncConditionSetsApi`][permit.api.sync_api_client.SyncConditionSetsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Condition Sets](https://api.permit.io/v2/redoc#tag/Condition-Sets).
