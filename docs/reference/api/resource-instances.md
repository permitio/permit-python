# Resource instances

`permit.api.resource_instances` is a [`ResourceInstancesApi`][permit.api.resource_instances.ResourceInstancesApi] on the async client and a
[`SyncResourceInstancesApi`][permit.api.sync_api_client.SyncResourceInstancesApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Resource Instances](https://api.permit.io/v2/redoc#tag/Resource-Instances).
