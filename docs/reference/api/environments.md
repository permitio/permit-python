# Environments

`permit.api.environments` is a [`EnvironmentsApi`][permit.api.environments.EnvironmentsApi] on the async client and a
[`SyncEnvironmentsApi`][permit.api.sync_api_client.SyncEnvironmentsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Environments](https://api.permit.io/v2/redoc#tag/Environments).
