# Resource roles

`permit.api.resource_roles` is a [`ResourceRolesApi`][permit.api.resource_roles.ResourceRolesApi] on the async client and a
[`SyncResourceRolesApi`][permit.api.sync_api_client.SyncResourceRolesApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Resource Roles](https://api.permit.io/v2/redoc#tag/Resource-Roles).
