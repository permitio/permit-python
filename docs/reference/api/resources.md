# Resources

`permit.api.resources` is a [`ResourcesApi`][permit.api.resources.ResourcesApi] on the async client and a
[`SyncResourcesApi`][permit.api.sync_api_client.SyncResourcesApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Resources](https://api.permit.io/v2/redoc#tag/Resources).
