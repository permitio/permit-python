# Groups

`permit.api.groups` is a [`GroupsApi`][permit.api.groups.GroupsApi] on the async client and a
[`SyncGroupsApi`][permit.api.sync_api_client.SyncGroupsApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[Groups](https://api.permit.io/v2/redoc#tag/Groups).
