# User invites

`permit.api.user_invites` is a [`UserInvitesApi`][permit.api.user_invites.UserInvitesApi] on the async client and a
[`SyncUserInvitesApi`][permit.api.sync_api_client.SyncUserInvitesApi] on the blocking client. The REST API
reference documents the endpoints behind it under
[User Invites](https://api.permit.io/v2/redoc#tag/User-Invites).
