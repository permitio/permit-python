# Elements

`permit.elements` logs users into Permit Elements, the embeddable UI components. It is an
`ElementsApi` on the async client and a `SyncElementsApi` on the blocking client. For
embedding Elements, see the
[Elements overview on docs.permit.io](https://docs.permit.io/embeddable-uis/overview/).
